🔎 Preguntas avanzadas que responde la revisión

Al analizar el modelo se añaden avisos específicos para estas cuatro áreas. Úsalos como checklist de revisión técnica.
FKs y cardinalidadDetecta campos tipo id_* sin FOREIGN KEY y propone 0..N, 1..N, 0..1 o 1..1 según nulabilidad y unicidad.
Índices frecuentesSugiere índices para FKs, búsquedas por estado/fecha, tablas de historial y combinaciones típicas de consulta.
NormalizaciónMarca tablas demasiado anchas o con grupos de columnas de responsabilidades distintas.
Tipos de datoRevisa fechas como texto, booleanos como texto, importes imprecisos e identificadores incompatibles.

🔁 Conversor SQL entre bases de datos

ℹ️ Acerca de esta herramienta y limitaciones

Convierte modelos SQL en diagramas visuales, detecta problemas comunes y genera documentación exportable. Especialmente diseñada para revisar SQL generado por IA.

  • No cubre todos los dialectos SQL ni toda la sintaxis posible.
  • Puede generar falsos positivos en modelos con convenciones no estándar.
  • Los resultados dependen de que el SQL tenga claves y relaciones declaradas.
  • No sustituye una revisión de base de datos profesional.
